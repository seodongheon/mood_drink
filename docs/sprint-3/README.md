# 🎨 Sprint 3: 프론트엔드 UI/UX & 유효성 검증 시스템

## 📌 1. 스프린트 개요
- **목표**: PRD 화면 명세 및 입력 유효성 검사 요구사항을 완벽히 반영한 인터랙티브 프론트엔드 UI 컴포넌트 개발
- **기간 (예정)**: Day 4 ~ Day 5
- **담당 영역**: Frontend, UI/UX, Client State

---

## 🎯 2. 세부 과업 (Tasks)

- [ ] **Task 3.1: 입력창 고도화 및 300자 카운터/제한**
  - 최대 300자 입력 제한 물리적 방어 (`maxLength={300}`)
  - 우측 하단 실시간 글자 수 카운터 (`{text.length} / 300`)
  - 300자 초과 텍스트 붙여넣기 시 300자로 자동 잘라내기(Truncate)
- [ ] **Task 3.2: 동적 유효성 검사 및 에러 경고 UI**
  - 0자(빈칸) 입력 시: 입력창 붉은색 테두리 + 하단 *"오늘 하루를 짧게라도 들려주세요!"* 빨간색 경고 문구 표시
  - 5자 미만 입력 시: 하단 *"조금 더 자세히 들려주세요!"* 경고 문구 표시
  - 정상 텍스트 입력 시 실시간으로 경고 상태 해제
- [ ] **Task 3.3: '추천받기' 액션 버튼 & 로딩 인터랙션**
  - 대기 상태: `추천받기` (결과 확인 후에는 `다시 추천받기`로 변경)
  - 처리 중: `고민 중...` 텍스트 + `LoaderCircle` 회전 스피너 + 버튼 `disabled` 처리
- [ ] **Task 3.4: 결과 카드(Result Card) 영역 레이아웃 및 트랜지션**
  - 기본 상태: 숨김 (`result === null`)
  - 결과 수신 시: 입력창 하단에 Fade-in / Slide-up 애니메이션과 함께 노출
  - 카드 구성: 공감 멘트 카드, 주종 카드, 안주 카드

## ✅ 4. 완료 기준 (Definition of Done)
- [ ] 빈 입력 또는 5자 미만일 때 버튼 클릭 시 붉은 경고 멘트가 노출되고 API 호출이 차단된다.
- [ ] 버튼 클릭 시 '고민 중...' 스피너가 활성화되고 중복 클릭이 방지된다.
- [ ] 결과 카드가 시각적으로 깨짐 없이 미려하게 렌더링된다.
