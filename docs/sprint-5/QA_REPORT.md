## 🛡️ 2. PRD 5대 예외 처리 상세 검증 결과

### 1) 빈칸(0자) 및 최소 글자 수(5자 미만) 방어
- **입력: `""` (공백)**
  - 결과: 테두리 `border-destructive` 붉은색 강조 + `"오늘 하루를 짧게라도 들려주세요!"` 경고 문구 노출 및 API 요청 차단 ✅
- **입력: `"힘들다"` (3자)**
  - 결과: `"조금 더 자세히 들려주세요!"` 경고 문구 노출 및 API 요청 차단 ✅
- **입력: `"오늘 운동하고 와서 너무 힘들어"` (18자)**
  - 결과: 실시간으로 모든 경고 상태 자동 해제 및 정상 제출 ✅

### 2) 최대 글자 수(300자) 제한 및 Truncate
- **입력: 500자 장문 텍스트 복사-붙여넣기**
  - 결과: 즉시 300자로 슬라이스(Truncate)되며 카운터 `300 / 300` 유지 ✅

### 3) 3초 타임아웃(Timeout) 및 Fallback 엔진
- **시나리오: AI 서버 응답이 3,000ms를 초과하는 지연 상황**
  - 결과: `AbortController`에 의해 요청이 자동 중단되고 크래시 없이 즉시 PRD 지정 Fallback 문구(*"AI가 너무 깊게 고민하네요! 오늘은 무조건 시원한 맥주와 치킨을 추천합니다."*) 및 `생맥주` + `후라이드 치킨` 카드가 렌더링됨 ✅

### 4) AI API 5xx 오류 및 네트워크 단절
- **시나리오: 네트워크 오프라인 또는 서버 500 에러 발생**
  - 결과: UI가 멈추거나 깨지지 않고 *"일시적인 연결 문제가 발생했습니다. 잠시 후 다시 시도해 주세요."* 에러 알림 배너가 노출되며, '추천받기' 버튼이 즉시 활성화되어 사용자가 즉각 재시도할 수 있음 ✅

### 5) AI 비정상 데이터 및 파싱 에러 방어 (UI Protection)
- **시나리오: AI가 정해진 JSON 형식을 어기거나 비정상적인 줄글을 반환할 때**
  - 결과: 백엔드 및 클라이언트의 Zod 스키마 2차 방어선이 이를 포착하여 사용자의 기분 키워드에 맞는 스마트 Fallback 데이터로 안전하게 대체 렌더링 ✅
