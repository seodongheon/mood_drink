## 🎯 2. 세부 과업 (Tasks)

- [ ] **Task 5.1: PRD 6대 완료 조건 전수 검증 (Verification Matrix)**
  - [ ] 1. 사용자가 텍스트를 입력하고 버튼을 누르면 추천 결과(주종 1개, 안주 1개, 공감 멘트 1~2문장)가 정상 출력되는가?
  - [ ] 2. 빈 입력(0자) 또는 5자 미만일 때 조건별 붉은색 경고 문구가 뜨고 API 호출이 차단되는가?
  - [ ] 3. 300자 입력 제한 및 300자 초과 텍스트 자동 잘라내기(Truncate)가 정상 작동하는가?
  - [ ] 4. AI 처리 중에 '고민 중...' 텍스트와 회전 로딩 스피너가 표시되고 버튼이 비활성화되는가?
  - [ ] 5. 3초 초과(타임아웃), 네트워크 에러, 서버 오류(5xx), 파싱 실패 시 화면이 죽지 않고 Fallback 결과 또는 안내 메시지가 뜨는가?
  - [ ] 6. 결과 확인 후 언제든지 '다시 추천받기' 버튼을 눌러 새로운 추천을 받을 수 있는가?
- [ ] **Task 5.2: 반응형 레이아웃 및 웹 접근성(A11y) 점검**
  - 모바일(iOS/Android), 태블릿, 데스크톱 해상도별 레이아웃 검수
  - 스크린 리더 지원을 위한 `aria-live="polite"`, `role="alert"`, 시맨틱 태그 구조 점검
- [ ] **Task 5.3: 성능 최적화 및 프로덕션 빌드 검증**
  - `pnpm build`를 통한 TypeScript 타입 에러 및 린트 무결성 검증
  - First Contentful Paint (FCP) 및 초기 로딩 속도 최적화
